# PRIVACY Release Plan

The final `PRIVACY.md` must document:

- encrypted principal, eligible/pending weight, prize, withdrawal claims, reserves, and draw intermediates;
- ACL ownership for users, the pool, snapshots, winner handle, prize, and settlement values;
- public wallet/contract addresses, slot existence, epoch timing, transactions, VRF trail, final winner, and aggregate settlements;
- ciphertext-handle metadata and aggregate amount/timing leakage;
- transaction correlation and prize side-information limits;
- public winner rationale;
- browser/wallet/frontend compromise boundary;
- local reveal and privacy-safe logging/storage rules;
- exact non-claims: no anonymity, hidden addresses, invisible timing, or fully private transaction graph.

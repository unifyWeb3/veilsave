# README Release Plan

The final README will be written from verified implementation and deployment evidence. It must include:

- literal product description and `TEST YIELD` versus `LIVE STRATEGY YIELD` labeling;
- why amount confidentiality matters and what remains public;
- 16-slot, weekly-epoch product behavior;
- system diagram and four-contract responsibilities;
- local prerequisites and exact install/test commands;
- Sepolia deployment manifest and source-verification links;
- reproducible demo sequence;
- HCU/gas, VRF, winner ACL/decryption, FIFO, and strategy evidence;
- permissionless recovery actions;
- known limitations and mandatory pre-production gates.

Do not publish placeholder addresses, unverified claims, APY, anonymity language, or a stronger public-verification claim than encrypted weights permit.
